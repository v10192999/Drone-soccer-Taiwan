# 無人機足球一站式學習平台

鍾兆羽老師整理 © 2026

給國中小到高中無人機足球社團與課程使用的單頁教學平台，打開 `index.html` 即可使用，不需要安裝。

## 內容

| 模組 | 單元 |
|---|---|
| 認識無人機 | 種類・用途・法規、台灣的無人機與足球發展、世界的無人機足球 |
| 學規則 | FAI 規則介紹、總統盃 2026 規則（依教育部 115 年國中小組簡章）、規則小測驗 |
| 學飛行 | 搖桿與基本操作、飛行原理、飛行訓練關卡 |
| 上場比賽 | 3D 戰術板、戰術範例庫、比賽計時計分板、隊伍與器材管理 |
| 動手做 | 球機構造 3D、維修手冊 |
| 教學資源 | 八節課教案與學習單、中英詞彙表 |

## 使用說明

- 需要網路連線（3D 套件 three.js 與字型由 CDN 載入）。
- 訓練紀錄、隊伍與器材管理資料存在各自瀏覽器中，不會跨裝置同步；可用「匯出備份」存成 JSON。
- 教學頁以 20 cm 有刷教育用球機為準；總統盃比賽使用無刷球機，規則相同。
- 規則內容以教育部與 FAI 公告為準，正式比賽以裁判與賽事委員會判定為準。
